Plugin Screen Capture

Versión 2.0 • Resolume 7+

Manual técnico para la instalación y configuración avanzada de captura de ventanas en tiempo real.

Instalación

Paso 01 Localizar Archivo

Encuentre el archivo ScreenCapture.dll en su paquete de descarga.

Paso 02 Copiar a Efectos

Pegue el archivo en:
Documentos\Resolume Arena\Extra Effects

Paso 03 Cargar en Resolume

Busque "Screen Capture" en la pestaña Sources y arrástrelo a un clip.

Flujo de Trabajo

El sistema utiliza un selector de ventanas dinámico en lugar de un menú desplegable.

Window Select Deslizador principal (0.0 - 1.0). Muévalo lentamente para recorrer todas las aplicaciones abiertas.
Refresh List Use este botón si abre una nueva ventana después de haber cargado el efecto.
⚠️
Modo Ventana Requerido Las aplicaciones (juegos, reproductores) deben ejecutarse en Modo Ventana o Borderless. El modo "Pantalla Completa Exclusiva" detendrá la captura si la ventana pierde el foco.

Ajustes de Imagen (Crop)

Herramientas para limpiar la captura y ajustar la composición.

Crop (L/R/T/B) Cuatro deslizadores para recortar bordes no deseados (barras de título, marcos de ventana).
Pos X / Pos Y Desplaza la imagen dentro del lienzo.
0.5 = Centro | < 0.5=Izquierda/Abajo |> 0.5 = Derecha/Arriba
Fit Aspect Ratio Corrige la distorsión. Actívelo si la ventana capturada se ve estirada o aplastada.
Swap RB Intercambia canales Rojo y Azul. (Corrección de color para ciertas GPUs).

Captura de Navegadores

Para capturar Chrome o Edge sin que la pantalla se vea negra, debe desactivar la aceleración de hardware o usar "flags" de inicio.

Método Recomendado: Flags de Inicio

Edite el acceso directo de su navegador y agregue estos comandos al final del campo "Destino":

--disable-gpu --disable-d3d11 --disable-software-rasterizer

Ejemplo completo:

"C:\Program Files\Microsoft\Edge\Application\msedge.exe" --disable-gpu

Método Alternativo: Ajustes

Vaya a Configuración > Sistema en el navegador y desactive la opción "Usar aceleración de hardware".
