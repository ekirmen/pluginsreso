AUTOMASK PRO

TRIPLE KEYER V2.1

El eliminador de fondos inteligente definitivo para Resolume.

¿Qué es AutoMaskPro?

AutoMaskPro es un plugin FFGL de alta gama diseñado específicamente para VJs y creadores de contenido que buscan un recorte de croma perfecto sin complicaciones. Compatible con tarjetas gráficas Intel UHD y optimizado para máxima fluidez en vivo.

Instalación

Paso 1: Copia el archivo AutoMaskPro.dll.
Paso 2: Pégalo en tu carpeta de efectos de Resolume:
C:\Program Files\Resolume Avenue\plugins\vfx (o tu ruta personalizada).
Paso 3: Abre Resolume. En la pestaña de efectos, busca "AutoMaskPro" y arrástralo a tu clip.

Guía de Parámetros

Auto_Pick
Activa el muestreo automático de color basado en las esquinas de tu video. ¡El plugin decide por ti!
Key_Color 1, 2, 3
Selecciona hasta 3 tonos diferentes para borrar. Ideal para fondos con sombras o degradados.
Threshold (1-3)
Ajusta la fuerza del recorte para cada color. Úsalo para borrar zonas difíciles.
Softness
Suaviza los bordes para una integración perfecta con el fondo.
Edge_Erode
"Encoge" el recorte hacia adentro. Úsalo para eliminar ese odiado "filo verde" en los bordes.
Spill_Removal
Elimina los reflejos verdes que se filtran en tu objeto (especialmente en logos metálicos).
