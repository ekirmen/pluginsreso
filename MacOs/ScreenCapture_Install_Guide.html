Descripción General

Qué es Screen Capture y qué puedes hacer con él

🖥️ ¿Qué es Screen Capture?

Screen Capture es un plugin FFGL (Free Frame GL) de tipo Source para Resolume Arena / Avenue. Permite capturar en tiempo real el contenido de cualquier ventana o pantalla de tu Mac y utilizarlo como fuente de video dentro de tus composiciones.

🎯

Captura Selectiva

Elige cualquier ventana abierta para capturar su contenido

✂️

Crop Dinámico

Recorta área específica con controles Left, Right, Top, Bottom

🔄

Flip & Swap

Voltea horizontal/vertical e intercambia canales R/B

🖱️

Cursor Visible

Opción para mostrar u ocultar el cursor del sistema

📐

Fit Mode

Ajusta la proporción de aspecto automáticamente

↔️

Posición X/Y

Desplaza la imagen capturada dentro del frame

ℹ️ Compatibilidad

Este plugin es compatible con Resolume Arena 7+ y Resolume Avenue 7+ en macOS. Funciona en Macs con procesador Intel (x86_64) y Apple Silicon (M1/M2/M3/M4) de forma nativa.

Instalación

Pasos para instalar el plugin en tu Mac

1

Localiza el archivo del plugin

El plugin se entrega como un archivo ScreenCapture.bundle. Este es el único archivo necesario para la instalación.

2

Abre la carpeta de destino

Abre Finder y navega a la carpeta de plugins FreeFrame. Puedes usar el atajo Cmd + Shift + G (Ir a carpeta) y pegar la ruta:

# Carpeta global (todos los usuarios)
/Library/Graphics/FreeFrame/

O alternativamente la carpeta del usuario actual:

# Carpeta del usuario
~/Library/Graphics/FreeFrame/
3

Crea la carpeta si no existe

Si la carpeta FreeFrame no existe, puedes crearla desde la Terminal:

$ sudo mkdir -p /Library/Graphics/FreeFrame/
4

Copia el plugin

Arrastra ScreenCapture.bundle dentro de la carpeta FreeFrame. También puedes usar la Terminal:

$ cp -R ScreenCapture.bundle /Library/Graphics/FreeFrame/
5

Reinicia Resolume

Cierra completamente Resolume y vuelve a abrirlo. El plugin se detectará automáticamente al iniciar.

✅ Resultado esperado

Al abrir Resolume, encontrarás "Screen Capture" en la sección Sources del panel de contenido. Arrastra el plugin a cualquier capa para comenzar a capturar.

📁 Estructura del Plugin

El archivo ScreenCapture.bundle es una carpeta con la siguiente estructura interna:

📂 ScreenCapture.bundle/
   📂 Contents/
      📄 Info.plist ← Metadatos del bundle
      📂 MacOS/
         ⚙️ ScreenCapture ← Binario ejecutable (Universal)
      📂 _CodeSignature/
         🔐 CodeResources ← Firma de código
⚠️ Importante

No modifiques ni renombres los archivos dentro del .bundle. Esto invalidaría la firma de código y macOS podría bloquear el plugin.

Permisos y Configuración

Permisos necesarios y parámetros del plugin

🔒 Permiso de Grabación de Pantalla

macOS requiere que Resolume tenga permiso de Grabación de Pantalla para que el plugin pueda capturar ventanas. La primera vez que lo uses, macOS te pedirá que otorgues este permiso.

1

Abre Ajustes del Sistema

Ve a Ajustes del Sistema → Privacidad y Seguridad → Grabación de Pantalla

2

Habilita Resolume

Asegúrate de que Resolume Arena (o Avenue) esté en la lista y activado con el toggle en verde.

3

Reinicia Resolume

Después de otorgar el permiso, reinicia Resolume para que los cambios surtan efecto.

🎛️ Parámetros del Plugin

Una vez cargado en Resolume, el plugin expone los siguientes controles:

Parámetro Tipo Descripción
Capture Mode Opción Selecciona la ventana a capturar
Show Cursor Bool Muestra u oculta el cursor del sistema
Swap R/B Bool Intercambia canales Rojo y Azul
Fit Mode Opción Ajuste de aspecto (Stretch, Fit, Fill)
Flip H / Flip V Bool Volteo horizontal / vertical
Crop L/R/T/B Rango Recorte desde cada lado (0.0 — 1.0)
Position X / Y Rango Desplazamiento de la imagen capturada

Solución de Problemas

Problemas comunes y cómo resolverlos

❌ El plugin no aparece en Resolume

1. Verifica que el archivo esté en /Library/Graphics/FreeFrame/
2. Asegúrate de copiar toda la carpeta ScreenCapture.bundle, no solo su contenido interno
3. Reinicia Resolume completamente (Cmd + Q para cerrar, luego reabrir)

⚫ La captura muestra pantalla negra

1. Ve a Ajustes del Sistema → Privacidad → Grabación de Pantalla
2. Verifica que Resolume esté habilitado
3. Reinicia Resolume después de cambiar los permisos

🔒 macOS bloquea el plugin ("no identificado")

Si macOS muestra un mensaje de que el plugin no se puede abrir porque es de un desarrollador no identificado:

1. Abre Ajustes del Sistema → Privacidad y Seguridad
2. Busca el mensaje sobre ScreenCapture.bundle y haz clic en "Abrir de todas formas"
3. Alternativamente, elimina la cuarentena desde Terminal:

$ xattr -cr /Library/Graphics/FreeFrame/ScreenCapture.bundle

🎨 Los colores se ven invertidos

Si los colores rojo y azul están intercambiados, activa el parámetro "Swap R/B" en los controles del plugin dentro de Resolume.

1. Copiar ScreenCapture.bundle → /Library/Graphics/FreeFrame/
2. Dar permiso de Grabación de Pantalla a Resolume
3. Reiniciar Resolume
4. Buscar "Screen Capture" en Sources
