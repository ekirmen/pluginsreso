Alpha Edge FX

User Manual & Installation Guide for Resolume Arena/Avenue

1. Installation Guide

Installing Alpha Edge FX is straightforward. It works just like any other custom FFGL plugin in Resolume.

Step-by-Step Installation:

  1. Locate the compiled file: AlphaEdge.dll.
  2. Copy the `.dll` file.
  3. Navigate to your Resolume external plugins folder. The default location is usually:
    C:\Users\[Your_Username]\Documents\Resolume Arena\Extra Effects
  4. Paste the `.dll` file into that folder.
  5. Open Resolume Arena (or Avenue).
  6. Go to the top menu: Arena/Avenue -> Preferences.
  7. Select the Video (or Plugins) tab.
  8. Under the FFGL Plugin directories list, ensure your "Extra Effects" folder is listed and click the Refresh button.
Note: If Resolume was already open, you MUST click Refresh in the Preferences menu for the new plugin to appear in your library.

2. How to Use & Workflow

Alpha Edge FX is an Effect plugin, which means it needs to be applied to a source clip. It is specifically designed to work with visual content that has an Alpha Channel (transparency).

Basic Workflow:

  1. Drag and drop a transparent PNG logo, or generate a Native Text clip in Resolume.
  2. In the files/effects panel on the right, search for Alpha Edge FX.
  3. Drag the effect onto your clip or layer.
  4. Adjust the parameters to create solid strokes, neon glows, and drop shadows around the contours of your image.

3. Parameter Reference

The plugin is divided into functional sections. Here is what each slider controls:

Outer Edge / Stroke (Borders & Glowing)

Edge Color (Hue/Sat/Bri): Defines the color of the outer border.
Edge Width: Controls how wide or thick the border extends completely outwards from the transparent edge of your logo.
Edge Softness: At 0.0, creates a hard solid Stroke. As you increase this value, the solid border blurs outwards, turning into a Neon Glow / Bloom effect.
Glow Intensity: Adjusts the overall brightness and opacity of the outer edge/glow.

Inner Glow (Internal Volume)

Inner Color (Hue/Sat/Bri): Defines the color used to tint the inside of your logo.
Inner Glow Str (Strength): Controls how intensely the edge color "bleeds" inwards into the original image, creating a 3D inner shadow or inner neon tube effect.

Drop Shadow

Shadow Offset X / Y: Moves the drop shadow horizontally and vertically relative to the logo.
Shadow Spread: Controls how blurry or dispersed the drop shadow is.
Shadow Opacity: Controls the darkness (Alpha) of the shadow. Set to 0.0 to completely disable the shadow.

Linear Transparency Fade

These parameters allow you to smoothly mask out parts of the logo using a linear gradient, similar to a layer mask in Photoshop.

Fade Start X/Y & Fade End X/Y: Coordinates defining the start and end points of the transparency gradient across the screen.
Fade Strength: Controls the intensity of the fading effect. At 0.0, the image is fully visible. At 1.0, the image fades out precisely from the Start point to the End point.
VJ Tip: Link the Glow Intensity or Edge Width parameters to the Audio FFT (BPM) in Resolume so your logo's neon glow pulses in sync with the kick drum!

Alpha Edge FX

Manual de Usuario & Guía de Instalación para Resolume Arena/Avenue

1. Guía de Instalación

Instalar Alpha Edge FX es muy sencillo. Funciona exactamente igual que cualquier otro plugin FFGL externo en Resolume.

Instalación Paso a Paso:

  1. Ubica el archivo compilado: AlphaEdge.dll.
  2. Copia el archivo `.dll`.
  3. Navega hasta la carpeta de plugins externos de Resolume en tu computadora. La ruta por defecto suele ser:
    C:\Usuarios\[Tu_Usuario]\Documentos\Resolume Arena\Extra Effects
  4. Pega el archivo `.dll` dentro de esa carpeta.
  5. Abre Resolume Arena (o Avenue).
  6. Ve al menú superior: Arena/Avenue -> Preferencias (Preferences).
  7. Selecciona la pestaña Video (o Plugins).
  8. En la lista de directorios de Plugins FFGL, asegúrate de que tu carpeta "Extra Effects" esté en la lista y haz clic en el botón Actualizar (Refresh).
Nota: Si ya tenías Resolume abierto al momento de pegar el archivo, es OBLIGATORIO que hagas clic en 'Actualizar' en Preferencias para que el programa detecte el nuevo plugin.

2. Cómo Usarlo / Flujo de Trabajo

Alpha Edge FX es un Efecto (Effect), lo que significa que debe aplicarse encima de un clip fuente. Está diseñado específicamente para trabajar con contenido visual que posea un Canal Alpha (transparencia).

Flujo de Trabajo Básico:

  1. Arrastra un logotipo PNG transparente a una capa, o genera un clip de "Texto" nativo de Resolume.
  2. En el panel de archivos y efectos a la derecha, busca Alpha Edge FX en la lupa.
  3. Arrastra el efecto y suéltalo sobre tu clip o capa.
  4. Ajusta los deslizadores (sliders) para crear trazos sólidos, brillos de neón y sombras paralelas alrededor del contorno exacto de tu imagen.

3. Referencia de Parámetros

El plugin está dividido en secciones funcionales. Esto es lo que controla cada deslizador:

Outer Edge / Borde Exterior (Trazos y Resplandores)

Edge Color (Hue/Sat/Bri): Define el color del borde exterior mediante la clásica rueda de color.
Edge Width: Controla qué tan ancho o grueso es el borde que crece hacia afuera de tu logotipo.
Edge Softness: En 0.0, crea un "Trazo Sólido" con bordes duros. A medida que subes este valor, el borde se difumina y se suaviza, convirtiéndose en un Glow o Resplandor de Neón.
Glow Intensity: Ajusta el brillo general visual y la opacidad del borde/resplandor.

Inner Glow (Resplandor Interior)

Inner Color (Hue/Sat/Bri): Define el color utilizado para "teñir" el interior de tu logo desde los bordes.
Inner Glow Str (Fuerza): Controla la intensidad con la que el color interior invade la imagen original. Perfecto para dar volumen 3D o hacer que un logo blanco parezca un tubo de neón con luz concentrada.

Drop Shadow (Sombra Paralela)

Shadow Offset X / Y: Desplaza la ubicación de la sombra en el eje horizontal y vertical con respecto a tu logo.
Shadow Spread: Controla qué tan desenfocada, suave o dispersa es la sombra trasera.
Shadow Opacity: Controla el nivel de oscuridad (Transparencia) de la sombra. Déjalo en 0.0 si deseas apagar la sombra completamente para ahorrar recursos.

Degradado Lineal de Transparencia (Linear Fade)

Estos parámetros te permiten enmascarar "dibujando" un degradado de invisibilidad, como una máscara de capa en Photoshop, para fundir la base de un logo en color negro oscuro.

Fade Start X/Y & Fade End X/Y: Coordenadas que definen los puntos de inicio (Start) y final (End) en la pantalla por donde pasará el degradado direccional.
Fade Strength: Controla la intensidad del efecto de borrado. En 0.0, la imagen se ve completa. En 1.0, la imagen se desvanecerá gradualmente haciéndose transparente desde el punto Start al punto End.
VJ Tip: ¡Enlaza los parámetros de Glow Intensity o Edge Width a la animación de Audio FFT (BPM) nativa de Resolume para que el resplandor de tu logo palpite al ritmo del bombo (Kick)!
